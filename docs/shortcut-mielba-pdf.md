# 「Mielbaに登録」ショートカット作成ガイド

LINEなどで受け取った図面・工程表のPDFを、iPhone/iPadの共有シートから
直接Mielbaの現場に登録するためのiOSショートカットの作成手順。

- 管理者が1回作成すれば、iCloudリンクで全スタッフに配布できます(受け取る側はリンクをタップして「ショートカットを追加」するだけ)。
- サーバー側のAPI: `GET /api/share/sites`(現場一覧) / `POST /api/share/upload`(PDF登録)。
  認証は `Authorization: Bearer <SHARE_UPLOAD_TOKEN>`(Vercelの環境変数)。
- 対応: PDFのみ・**4MBまで**(Vercelの制限)。大きいPDFは従来どおり「現場を修正」から。

## 使い方(完成後のイメージ)

1. LINEでPDFを開く → 共有ボタン
2. 共有シートの「**Mielbaに登録**」をタップ
3. 現場を一覧から選ぶ → 種別(図面/工程表)を選ぶ
4. 「◯◯を△△の図面に登録しました」と通知が出て完了
   (Mielbaの現場詳細 › 図面・工程表 に表示され、ビューア・共有もそのまま使えます)

## 作成手順(ショートカットApp・約5分)

以下、`<トークン>` は管理者から共有された SHARE_UPLOAD_TOKEN の値に置き換えてください。

1. **ショートカットApp** → 右上「＋」で新規作成 → 名前を「**Mielbaに登録**」にする
2. 上部の **ⓘ(詳細)** → 「**共有シートに表示**」をON → 「受け取る内容」を「**PDF**」と「**ファイル**」だけに絞る
3. アクションを順に追加:

   **① URLの内容を取得**(1つ目)
   - URL: `https://mielba.vercel.app/api/share/sites`
   - 「方法」: GET
   - 「ヘッダ」を追加: キー `Authorization` / 値 `Bearer <トークン>`

   **② 辞書の値を取得**
   - 「**すべてのキー**」を取得 / 入力: ①の「URLの内容」

   **③ リストから選択**
   - 入力: ②の「辞書の値」
   - プロンプト: 「どの現場に登録しますか？」

   **④ 辞書の値を取得**
   - 「**キーの値**」を取得 / キー: ③の「選択した項目」 / 辞書: ①の「URLの内容」
   - ※これが現場ID(siteId)になります

   **⑤ 辞書**(新しい辞書を作る)
   - `図面` → `DRAWING`
   - `工程表` → `SCHEDULE`

   **⑥ 辞書の値を取得**「すべてのキー」(入力: ⑤) → **⑦ リストから選択**(プロンプト:「種別を選んでください」) → **⑧ 辞書の値を取得**「キーの値」(キー: ⑦の選択した項目 / 辞書: ⑤)

   **⑨ URLの内容を取得**(2つ目)
   - URL: `https://mielba.vercel.app/api/share/upload`
   - 「方法」: POST / 「本文をリクエスト」: **フォーム**
   - フォームのフィールドを3つ追加:
     - `file`(種類: **ファイル**) = 変数「**ショートカットの入力**」
     - `site`(種類: テキスト) = ④の値(現場ID)
     - `kind`(種類: テキスト) = ⑧の値
   - 「ヘッダ」: `Authorization` / `Bearer <トークン>`(①と同じ)

   **⑩ 辞書の値を取得**「キーの値」 キー: `message`(辞書: ⑨の「URLの内容」) → **⑪ 通知を表示**(本文: ⑩の値)

4. 完了。LINEでPDFを開き、共有 → 「Mielbaに登録」で動作確認。

## スタッフへの配布

作成したショートカットを長押し → 「共有」 → 「iCloudリンクをコピー」 → 社内LINE等で共有。
受け取った人はリンクを開いて「ショートカットを追加」するだけです(トークンはショートカット内に含まれるため入力不要)。

## トークンを変えたいとき

Vercelの環境変数 `SHARE_UPLOAD_TOKEN` を変更して再デプロイし、ショートカット内の
2箇所の `Authorization` ヘッダを新しい値に更新して再配布してください。
